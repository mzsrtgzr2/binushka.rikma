{%- comment -%} The workshops to show, in the order to show them, as `projects_ordered`. A workshop only carries `order` once it has been placed by hand in the backoffice. Everything else keeps falling back to the date, so a workshop added outside the backoffice still appears, and a site where nothing has ever been reordered reads chronologically: the next workshop first. {%- endcomment -%} {%- assign projects_placed = '' | split: '' -%} {%- assign projects_by_date = '' | split: '' -%} {%- for project in site.projects -%} {%- unless project.hide -%} {%- if project.order -%} {%- assign projects_placed = projects_placed | push: project -%} {%- else -%} {%- assign projects_by_date = projects_by_date | push: project -%} {%- endif -%} {%- endunless -%} {%- endfor -%} {%- assign projects_placed = projects_placed | sort: 'order' -%} {%- assign projects_by_date = projects_by_date | sort: 'date' -%} {%- assign projects_ordered = projects_placed | concat: projects_by_date -%}
